# Recall Learning

Recall is a personal learning workspace for turning source notes into active study material and tracking progress over time.

## Language

**Workspace**:
A named learning area that groups related sources, study material, and progress.
_Avoid_: Project, tenant

**Source**:
A note, page, or module that provides the material used to create study content.
_Avoid_: Input, document

**Quiz**:
A study set made of single-answer multiple-choice and true/false questions with explanations.
_Avoid_: Exam, test

**Flashcard set**:
A study set made of front-and-back cards reviewed from memory and marked known or needs review.
_Avoid_: Cards, deck

**Attempt**:
A learner's session for a quiz or flashcard set, including responses, score, duration, and completion state.
_Avoid_: Run, submission

**Learning task**:
A trackable unit of work in a learning roadmap.
_Avoid_: Ticket, issue

**Concept**:
A focused subject area that organizes related source material and learning tasks.
_Avoid_: Topic, category
